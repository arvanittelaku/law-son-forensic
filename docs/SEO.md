# SEO: sitemap.xml and robots.txt

This document describes how `public/sitemap.xml` and `public/robots.txt` are produced and kept in sync with the Lawson Forensic app.

## Overview

Both files are **generated by a Node script**, not maintained by hand. That keeps every public URL aligned with the same inventory used by verification tooling.

| Output | Path | Generator |
|--------|------|-----------|
| XML sitemap | `public/sitemap.xml` | `scripts/generate-seo.ts` |
| robots.txt | `public/robots.txt` | `scripts/generate-seo.ts` |

Next.js serves files in `public/` at the site root (`/sitemap.xml`, `/robots.txt`). The App Router does **not** use `app/sitemap.ts` or `app/robots.ts` for these files.

## URL inventory (`buildPublicUrlInventory`)

The script imports `buildPublicUrlInventory` from `lib/seo/publicUrlInventory.ts`. That function assembles paths that should appear in search, then maps them to absolute URLs with the canonical host **https://www.lawsonforensic.com**.

The inventory includes:

- **Static app routes** — `APP_STATIC_PATHS` (home, about, services hub, each `/services/[id]`, practice areas hub and slugs, case studies, qualifications, how we work, FAQ, insights hub and articles, contact, cookies, privacy, terms).
- **Excluded from sitemap** — `/thank-you` (listed in `NON_INDEX_PATHS` and disallowed in robots).

The combined list is deduplicated, sorted, and exposed as `allUrls` (absolute) and `allPaths` (pathname only).

## Sitemap generation

For each URL in `inventory.allUrls`, the script emits a sitemaps.org `<url>` entry with:

- `<loc>` — Absolute URL
- `<lastmod>` — Calendar date when generation runs (UTC `YYYY-MM-DD`)
- `<changefreq>` — Heuristic by path (`getSitemapChangeFreq`)
- `<priority>` — Heuristic by path (`getSitemapPriority`)

## robots.txt generation

`robots.txt` is a template in the same script (`renderRobots()`):

- Allows all crawlers on `/`
- Disallows `/thank-you` and `/api/`
- Declares `Sitemap: https://www.lawsonforensic.com/sitemap.xml`

## Commands

```bash
npm run seo:generate   # Regenerate sitemap.xml + robots.txt
npm run seo:verify       # Fail if sitemap URLs drift from inventory
```

`seo:generate` runs automatically before `npm run build`.

After adding a new static route, add its path to `APP_STATIC_PATHS` in `lib/seo/publicUrlInventory.ts`, then run `seo:generate`.

## Deployment (Netlify)

`netlify.toml` sets content types for crawlers:

- `/sitemap.xml` → `application/xml`
- `/robots.txt` → `text/plain`

## Operational notes

- Canonical host is **https://www.lawsonforensic.com** (`lib/site.ts` and robots `Sitemap:` line).
- Legacy URLs `/expert-witness`, `/investigations`, and `/fees` redirect via `next.config.ts` to the new service or contact routes.
